# Présentation du projet

Dans le cadre de cette SAE, nous avons réalisé un site web consacré à Ubisoft, une entreprise française spécialisée dans le domaine du jeu vidéo.

L’objectif de notre projet est de présenter Ubisoft, son histoire, ses activités et quelques-unes de ses principales licences à travers un site web moderne et facile à utiliser.
## Choix de conception

Pour la réalisation de ce site consacré à Ubisoft, nous avons opté pour une approche moderne et épurée, rappelant l'univers du jeu vidéo tout en restant très professionnel. 
* **Charte graphique :** Nous avons choisi des couleurs contrastées (fonds sombres ou clairs avec des touches de couleurs vives) pour mettre en valeur les images des jeux et les différents logos de l'entreprise.
* **Ergonomie et navigation :** L'arborescence a été pensée pour être la plus intuitive possible. Le menu de navigation principal permet d'accéder rapidement aux informations clés (présentation, activités, économie, contact) depuis n'importe quelle page. 
* **Mise en page :** Nous avons respecté une structure sémantique stricte (HTML5) avec des titres bien hiérarchisés pour faciliter la lecture. Le CSS a été conçu de manière homogène pour que l'identité visuelle soit conservée sur l'ensemble des 5 pages.
